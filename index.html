E.E.T.P. N° 468

Simulador de Diagnóstico de Hardware

Espacio Curricular: Hardware IV — 6.º Año

Propósito pedagógico: esta es una actividad áulica de simulación. Permite practicar un protocolo ordenado de diagnóstico de fallas en una PC de escritorio (códigos POST, mediciones eléctricas, integridad de datos y pruebas de estrés) sin ningún riesgo para el equipamiento real. No se solicita ningún tipo de dato personal sensible ni credencial: solo el nombre y apellido del alumno/a para identificar el informe de la actividad.

Datos del Alumno/a

Estos datos se usan únicamente para encabezar el informe de la actividad. No se envían a ningún servidor: todo el simulador funciona dentro de tu navegador.
